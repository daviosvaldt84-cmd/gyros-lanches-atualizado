# Gyros Lanches — identidade visual atualizada

Esta versão aproxima o site da identidade da logo oficial do Gyros Lanches.

## Principais mudanças

- Paleta principal em preto, branco, amarelo, âmbar e dourado.
- Logo oficial aplicada no cabeçalho, hero, seções promocionais e rodapé.
- Fundo escuro com brilho dourado sutil e maior contraste.
- Faixas inclinadas inspiradas na placa central da logo.
- Divisores ornamentais inspirados no padrão grego circular da marca.
- Cards, botões, menu, modal e barras móveis redesenhados.
- Favicon e cor do navegador atualizados com a marca.
- Conteúdo, cardápio, links, mapa e funções originais preservados.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```

## Atualizar o site conectado ao GitHub/Vercel

Copie os arquivos desta pasta para o repositório existente e execute:

```bash
git add .
git commit -m "Atualizar identidade visual do Gyros Lanches"
git push
```

A Vercel deverá iniciar um novo deploy automaticamente.
